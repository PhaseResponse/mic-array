# Mic Array Polar Plot

Interactive beam patterns for 2, 3 and 4 microphones (line, triangle, tetrahedron).

**[Open Live Simulator](https://phaseresponse.github.io/mic-array/)**

* **d/λ, d:** mic spacing in wavelengths and in cm.
* **2 and 3 mics:** set each mic's gain, polarity and delay (τ = cos θ · d/c), relative to mic0.
* **4 mics:** set the look direction (azimuth, elevation). Gains, polarities and delays are computed by Delay and Sum or MVDR (superdirective, SNR gain kept ≥ 0 dB).
